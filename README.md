# seed-laptop

**▶ Live: https://sjgant80-hub.github.io/seed-laptop/**

THE SEED LAPTOP, Stage 1: plant one signed seed on a machine with a minimal base, and a whole working office grows
from it (documents, sheets, contacts, notes, accounts, PDF, mail at the edges, and Kar the conductor), owned and local.
Old-world files are translated only at the edges. Everything is backed up to an encrypted vault whose key stays with
the owner.

Claims were sealed before any code (`measure/claims.json`, seal 1); each is measured once, and a failed claim is kept.

Powered by the Konomi architecture, created by Thomas Frumkin.
